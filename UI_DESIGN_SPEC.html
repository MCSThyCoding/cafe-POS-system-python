📱 Screen Specifications

1. Login Screen

Layout: Background: Linear gradient (135deg, #fffaf0, #fdebd0), Centered card (max 420px)

Elements:

  1. Logo Badge: 56x56px, Brand background, emoji ☕
  2. Title: "Cafe POS", 26px, centered
  3. Subtitle: "Coffee Shop Management System", 14px muted
  4. Username Input: Full width, placeholder "Enter your username"
  5. Password Input: Full width, type password
  6. Login Button: Primary, block, "Login →"
  7. Demo Box: Credentials for Admin and Cashier

2. Main App Shell

Layout: Flex, min-height 100vh, Sidebar (240px) + Page Content (flex-1)

Sidebar Elements:

  1. Brand: "☕ Cafe POS", 20px bold
  2. Navigation: Point of Sale (☕), Dashboard (▦), Inventory (📦), Reports (📊)
  3. User Info: Name, Role badge, Logout button

3. Point of Sale Screen

Layout: Grid 2 columns, gap 20px

Left Column: Page Header + Category Chips + Product Grid

Right Column (Cart): Cart Items + Total Row + Payment Buttons + Complete Button

Categories: All, Coffee, Cold Drinks, Food, Tea

4. Dashboard Screen

Layout: Alert (if low stock) + Stats Grid (4 columns) + Charts Grid (2 columns) + Recent Orders Table

Stats: Today's Revenue, Today's Orders, Average Order, Total Products

Charts: Sales by Category (Pie), Top Selling Products (Bar)

5. Inventory Screen

Layout: Page Header + Search Bar + Table

Table Columns: Product, Category, Stock Level, Quantity, Price, Actions (Admin only)

Stock Status: Dot (good/low/out) + label

6. Reports Screen (Admin Only)

Layout: Page Header + Date Bar + Stats Grid + Charts Grid + Profit Analysis Table + Category Reports Table

Date Bar: Period dropdown (Daily/Monthly/Yearly) + Date/Month/Year picker

Stats: Total Revenue, Total Cost, Profit, Total Orders

Charts: Revenue Trend (Line), Profit by Product (Bar)

🔄 User Flows

1. Login Flow

1. User opens app 2. Sees login screen 3. Enters username and password 4. Clicks "Login →" 5. System validates credentials 6. If valid → Redirect to Dashboard/POS 7. If invalid → Show error message

2. POS Flow

1. User navigates to Point of Sale 2. Selects category filter (optional) 3. Clicks product to add to cart 4. Adjusts quantity (+/- buttons) 5. Selects payment method (Cash/Card) 6. Clicks "Complete Order" 7. Modal appears with order confirmation 8. Click "New Order" to reset

3. Dashboard Flow

1. User navigates to Dashboard 2. Views today's stats (revenue, orders, etc.) 3. Views sales by category chart 4. Views top products chart 5. Views recent orders table 6. Checks low stock alert (if any)

4. Inventory Flow (Admin)

1. Admin navigates to Inventory 2. Views all products with stock levels 3. Searches for specific product (optional) 4. Clicks "+ Add 10" to restock 5. Stock updates immediately

5. Reports Flow (Admin)

1. Admin navigates to Reports 2. Selects period type (Daily/Monthly/Yearly) 3. Selects date/month/year 4. Views stats and charts 5. Views profit analysis table 6. Views category reports 7. Clicks "Export Report" to download

6. Logout Flow

1. User clicks "Logout" in sidebar 2. System clears session 3. Redirects to login screen

⚡ Interactive States

Button States

  • Default: Normal appearance
  • Hover: Background darkens (brand-dark)
  • Active: Click feedback
  • Disabled: Opacity 0.5, cursor not-allowed
  • Loading: Spinner or loading text

Input States

  • Default: Border Line color
  • Focus: 2px solid Brand outline, border transparent
  • Error: Red border (optional)
  • Disabled: Gray background

Card States

  • Default: Normal shadow
  • Hover: Enhanced shadow (product cards)
  • Disabled: Opacity 0.5 (out of stock)

Navigation States

  • Default: Transparent border
  • Hover: Sand background
  • Active: Sand background + visual indicator

Payment Button States

  • Default: Light gray background
  • Selected: Green background, white text

📐 Responsive Design

Desktop (> 1000px)

  • Stats Grid: 4 columns
  • Charts Grid: 2 columns
  • POS: 2 columns (products + cart)
  • Sidebar: Fixed, 240px

Tablet (700px - 1000px)

  • Stats Grid: 2 columns
  • Charts Grid: 1 column
  • POS: 1 column (cart below products)
  • Sidebar: Fixed, 240px

Mobile (< 700px)

  • App Layout: Column (sidebar on top)
  • Sidebar: Full width, height auto, padding 12px
  • Navigation: Row, wrap
  • Brand: Margin-bottom 10px
  • User Info: Name/role hidden
  • Page Padding: 16px
  • Stats Grid: 2 columns or 1 column

♿ Accessibility

Color Contrast

  • Ensure text meets WCAG AA standards
  • Muted text should still be readable
  • Error messages should be high contrast

Focus States

  • All interactive elements should have visible focus states
  • Use 2px outline for keyboard navigation

ARIA Labels

  • Buttons should have descriptive labels
  • Form inputs should have associated labels
  • Modal should have aria-modal attribute

Keyboard Navigation

  • Tab order should be logical
  • Enter/Space to activate buttons
  • Escape to close modals

🎨 Notes for Figma Implementation

1. Create Components First

  • Build the design system (colors, typography, spacing)
  • Create reusable components (buttons, cards, inputs)
  • Use auto-layout for responsive components

2. Use Variables

  • Color variables for easy theming
  • Spacing variables for consistency
  • Typography scale

3. Create Screens

  • Start with login screen
  • Build app shell (sidebar + content)
  • Create each page as a separate frame
  • Use components for consistency

4. Interactive Elements

  • Create hover states for all buttons
  • Create focus states for inputs
  • Create disabled states
  • Create loading states

5. Responsive Design

  • Use constraints for responsive layouts
  • Create variants for different screen sizes
  • Test on mobile, tablet, desktop

6. Export Assets

  • Export icons as SVG
  • Export charts as PNG/SVG
  • Ensure correct scale for retina displays
